# Благотворительная платформа

## О проекте

Веб-интейрфейс для сбора благотворительных пожертвований. Платформа позволяет пользователям просматривать активные сборы, фильтровать их по категориям, делать пожертвования и сохранять историю своих переводов.

**Сайт разработан в рамках курсового проекта по дисциплине «Информационные технологии и программирование».**

## Функциональность

- Просмотр списка активных сборов
- Фильтрация сборов по категориям (Дети, Животные, Медицина, Экология, Пожилые)
- Поиск сбора по названию или описанию
- Детальная страница каждого сбора с прогресс-баром
- Система пожертвований с сохранением истории в localStorage
- Счётчик «помощи сегодня» (обнуляется раз в сутки)
- Страница отчётности с финансовыми отчётами
- Форма обратной связи с валидацией
- Адаптивная вёрстка (десктоп, планшет, телефон)

## Технологии

- **HTML5** — семантическая вёрстка
- **CSS3** — Flexbox, Grid, медиа-запросы, неоновый дизайн
- **JavaScript (Vanilla)** — вся логика на чистом JS без фреймворков
- **Fetch API** — загрузка данных из JSON-файла
- **localStorage** — сохранение истории пожертвований
